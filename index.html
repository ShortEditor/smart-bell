Hardware testing

Test with a low-voltage LED or unloaded relay module. A power indicator can stay on while the relay is off.

Have a qualified electrician handle any mains-powered bell installation. Secure Firebase access before using this with the college bell.
Change ESP32 Wi-Fi

Connect your ESP32 to another 2.4 GHz network. It must currently be online. Keep its old network available until the change finishes.

Upload the accompanying sketch once. Open Serial Monitor at 115200 baud and send PAIR with a newline to display the code. Keep it private for future changes. Passwords and pairing codes are not saved in this browser.

Upload the Wi-Fi-enabled sketch before using this form.
Wi-Fi changes briefly pause bell checks. Use a quiet time and a low-voltage test load. A failed connection triggers a return to the previous network. School networks requiring a browser sign-in or enterprise login are not supported.
Connection and privacy details

The Wi-Fi name and password are encrypted before being sent through Firebase. Only a device with your pairing code can read and accept them. This does not secure the existing bell commands or database status: Firebase access rules still need to restrict access to authorized users. Open this trusted file locally in a supported browser or serve it over HTTPS.
