🕐 RTC / Time Settings (DS3231)
The external DS3231 module keeps time independently of Wi-Fi. With a valid RTC and a downloaded timetable, the powered ESP32 can run its schedule offline. Use Sync from NTP for automatic accurate sync (recommended). App time requests still require both the page and ESP32 to reach Firebase. Manual set cannot reach an offline board.
🌐 Sync RTC from NTP (Internet Time)
Copies the ESP32’s NTP-synchronized clock to the DS3231 when correction is needed. Requires Internet and a successful NTP sync.

ℹ Use the battery specified for your exact DS3231 breakout. Never put a non-rechargeable CR cell in an enabled charging circuit. The battery preserves RTC time only; the ESP32 and bell still need their own power. Without a working backup battery, a power cut requires time synchronization again.
⚡ 230V AC is lethal. All mains wiring must be done by a licensed electrician in an insulated enclosure.
